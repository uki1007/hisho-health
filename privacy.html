プライバシーポリシー（Privacy Policy）

制定日: 2026年9月28日

1. このツールについて

hisho-health は、開発者本人だけが使う個人用ツールです。開発者本人が許可した範囲で、本人の Google Health のデータを読み取ります。一般の方には提供していません。

2. 読み取るデータ

Google Health API から、本人が許可した範囲の健康データ（睡眠、心拍数・安静時心拍数・心拍変動、心電図の記録、不規則な心拍の通知、血中酸素、呼吸数など）を読み取ります。読み取り専用で、Google Health のデータを書き換えることはありません。

3. 使い道

本人の健康管理のために、本人のパソコン上で表示する目的にだけ使います。

4. 保存と共有

読み取ったデータは本人のパソコンの中にだけ保存し、外部のサーバーには保存しません。第三者への提供・販売はせず、広告や信用評価には使いません。

hisho-health's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. 許可の取り消し

許可は Google アカウントの「サードパーティ製のアプリとサービス」 からいつでも取り消せます。

6. 問い合わせ

GitHub の Issues からお願いします。
